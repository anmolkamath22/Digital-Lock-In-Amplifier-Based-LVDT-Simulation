Digital Lock-In Amplifier for LVDT Displacement Sensing

Python models the LVDT, noise and 12-bit ADC and exports HDL test vectors. The Verilog lockin_top correlates each sample with a 20-entry Q1.14 sine LUT and adds up 200-sample windows. Its accumulators are then checked one by one against the Python golden model.

How it works

Signal chain

V1,2 = (A0 ± D/2)·sin(2πfc·t + φ), with D = K·x + αx³. The differential output D·sin(…) picks up white noise, hum, a DC offset, a tone interferer and drift. It is then quantised with q = clip(rint(v·2048/2.5)).

Verilog datapath

On each accepted sample the RTL computes product = sample × LUT[k] (signed 16×16 → 32-bit), adds it to a 40-bit accumulator and steps k modulo 20. On the 200th sample it latches the sum with output_valid and clears the accumulator. The displacement is x = 2S/(200·16384) · (2.5/2048) / K.

Magnitude and phase

lockin_top.v has only the in-phase channel. To measure phase, the backend runs the same RTL twice: once with the sine LUT, giving the I sum, and once with a cosine LUT, giving the Q sum. Each sum is converted to volts with V = 2S/(200·16384)·(2.5/2048). Magnitude is |V| = √(I²+Q²), the phase angle is φ = atan2(Q, I), and the displacement magnitude is |V|/K. A negative displacement appears as a phase near ±180°. Both channels are checked bit for bit against Python integer sums.

What to try
  • Raise the noise σ. The error grows roughly as σ / (K·√100).
  • Set the tone to 1000 Hz. A coherent interferer can't be told apart from real displacement.
  • Set the tone to 950 Hz and watch the beating leak through the rectangular window.
  • Set the phase error to 60°. The estimate scales by cos φ, because the design has only an I channel.
  • Set the tone above about 1.5 V. The ADC clips and correlation breaks down.
